# Перенос содержимого со старого сайта

⚠️ **Этот импорт запускается ОДИН раз.** Повторный запуск с `--replace`
стирает всё, что добавили в админке.

## Что случилось 10 августа

Файл `content.ndjson` содержит статьи без обложек — на момент его написания
обложек ещё не было. После первого импорта обложки загрузили через админку.
Второй запуск с `--replace` заменил документы целиком и обложки удалил.

`--replace` меняет не отдельные поля, а весь документ: чего нет в файле —
того не будет и в базе. Ошибка в том, что я дал команду с этим флагом
как обычный шаг, который можно повторить.

## Как запускать

**Первый раз, на пустой базе:**

```bash
cd /Users/diidentikit/otherworldly/site && npx sanity dataset import import/content.ndjson production
```

Без `--replace`. Если документ с таким адресом уже есть, команда об этом скажет
и ничего не тронет.

**Повторно — только так:**

```bash
cd /Users/diidentikit/otherworldly/site && npx sanity dataset import import/content.ndjson production --missing
```

`--missing` создаёт только те документы, которых в базе нет. Существующие
не трогает вообще.

**`--replace` не использовать.** Он нужен ровно в одном случае: когда вы
намеренно хотите откатить всё содержимое к состоянию из файла и потерять
правки кураторов.

## Что внутри

| | |
|---|---|
| `person-*` | четыре кураторки: имена, роли, биографии, портреты |
| `edition-2024`, `edition-2025` | прошедшие сезоны с описаниями и векторами |
| `article-*` | две публикации на «Пилигриме» — ведут наружу |
| `page-about`, `page-open-call` | разделы «О фестивале» и «Опен-колл» |
| `venue-gorka` | площадка |

Портреты подтягиваются с сервера Тильды при импорте и сохраняются в вашей
базе — зависимости от старого сайта не остаётся.

Сезон 2026 в файле **отсутствует намеренно**: он заведён вручную в админке,
и импорт не должен его трогать.
