# site — По-ту-сторонний

Next.js 16 (App Router) + Sanity. Студия встроена и живёт на `/studio`.

Дизайн-система — источник истины в `../case/11-specimen/index.html`.
Решения с номерами `D-nnn` — в `../case/07-process-log.md`.

## Запуск

```bash
npm install
npm run dev
```

**Проект Sanity не обязателен.** Пока `NEXT_PUBLIC_SANITY_PROJECT_ID` пуст, сайт
работает на демо-данных из `src/lib/seed.ts` — форма данных ровно та же, что вернёт
GROQ-запрос, поэтому подключение реального проекта не потребует править компоненты.

Сделано намеренно: репозиторий должен запускаться сразу после `npm install`, иначе
показать работу можно только вместе с ключами.

Чтобы подключить настоящий Sanity — скопируйте `.env.example` в `.env.local`
и заполните `NEXT_PUBLIC_SANITY_PROJECT_ID`.

## Решения, которые видно в коде

| Где | Что |
|---|---|
| `globals.css` | Токены объявлены **один раз**. В прототипах они лежали в семи файлах и успели разъехаться на пять вариантов примитива — систему сводили до переноса в код, а не после |
| `sanity/schemas/film.ts` + `event.ts` | Фильм и показ — разные документы (D-007). Только поэтому страница фильма может собрать все свои сеансы за историю фестиваля |
| `event.ts` | Носитель живёт у показа, а не у фильма: одна работа в 2025-м шла с цифры, в 2026-м идёт с плёнки |
| `lib/i18n.ts` | Нет английского — отдаём русский и ставим `lang="ru"` на элемент (D-006). Решение про доступность, а не про удобство |
| `components/TicketButton.tsx` | Пустой `timepadEventId` — кнопка «скоро в продаже», а не мёртвая ссылка (D-010). Сайт можно выпустить до аккаунта организатора |
| `[locale]/page.tsx` | Фаза сезона, обратный отсчёт и «проектор включится» читаются из ОДНИХ дат сезона (D-069) |
| `lib/meta.ts` | hreflang для обоих языков + `x-default` на русский: фестиваль петербургский, и для неизвестного языка это осмысленнее английского |
| `app/sitemap.ts` | Одна карта на оба языка — то, ради чего в D-003 выбраны подпути, а не поддомены |
| `api/revalidate` | Ревалидируются только маршруты, которых коснулся изменённый тип, а не весь кэш |
| `timetable/page.tsx` | Строка = 30 минут, `span` = длительность. Хронометраж читается как высота, накладки не спрятать (D-091) |
| `globals.css` | Ни одной линейки `1px solid`. Разделяет зазор и заливка (D-048) |
